## **Overview**
- Demonstrates reading, extracting, and scraping electronic text in R.

## **Main Sections**
- Reading local text and CSV files
- PDF text and table extraction using pdftools and tabulapdf
- Tidy conversion with tibble and basic file viewers
- Web scraping via rvest and RSelenium automation
- Database querying using SQL and dplyr tbl

## **Key Packages/Functions**
- readLines, read.csv, pdftools, tabulapdf, rvest, RSelenium, dplyr tbl

## **Why this matters**
- Equips students to access, process, and scrape textual data from various electronic sources and databases.
