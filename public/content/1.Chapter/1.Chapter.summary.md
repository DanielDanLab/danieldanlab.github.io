## **Overview**
- Demonstrates package management and vector transformation using base R and magrittr pipeline.

## **Main Sections**
- Package installation and updates commands  
- Vector sqrt, rounding, and filtering in base R  
- Magrittr pipeline for concise vector transformation  

## **Key Packages/Functions**
- installed.packages, old.packages, update.packages, install.packages, sqrt, round, magrittr pipe

## **Why this matters**
- Helps students learn essential package management and clear data transformation techniques in R programming.
